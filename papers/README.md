## Manuscript status

The Verification Copilot, Alignment Assurance Lab, and CloudGuard V4 documents are working papers or architecture addenda grounded in the current prototypes and automated tests. They distinguish implemented reference controls from proposed production integrations and future empirical studies. They are not accepted or peer-reviewed publications.

The CloudGuard V4 addendum should be read with the original course report, `projects/cloudguard-ai.md`, and `benchmarks/CLOUDGUARD_V4.md`. The original report remains a course artifact; V4 does not retroactively claim that the course implementation had the newer threat-governance, HITL, or audit controls.

The V6 integrity addendum records the evaluation-information-flow and privileged-CI/CD threat classes added after the initial V6 architecture. It should be read together with the main Alignment Assurance Lab working paper and `benchmarks/TRACE_ASSURANCE_V6.md`.

## Citation note

These artifacts are academic course, presentation, or working-paper materials, not peer-reviewed publications. Cite the title, authors, year, relevant course/institution context where applicable, and this repository URL. Do not describe them as accepted or published papers.
